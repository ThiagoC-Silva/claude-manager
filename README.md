# claude-manager

Mod `cc-manager` do Claude Code: painel ao lado do chat com a barra de contexto e as barras de uso da sessão de 5 horas e da semana.

## Instalação

No prompt de uma sessão do Claude Code no terminal:

```
/plugin install cc-manager --marketplace ThiagoC-Silva/claude-manager
```

Responda `y` para adicionar o marketplace e escolha o escopo (o de usuário, primeiro da lista, vale para todas as sessões).

Pelo shell:

```
claude plugin install cc-manager --marketplace ThiagoC-Silva/claude-manager
```

No app desktop, onde `/plugin` não funciona: clique em + ao lado da caixa do prompt, depois Plugins, Add marketplace com `ThiagoC-Silva/claude-manager`, e então Add plugin.
